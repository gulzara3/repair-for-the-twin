# Changelog

## 1.0.0 (2026-11-17)

First public release accompanying the manuscript.

- Python package `repair4twin` with the full corrupt, repair, predict and decide pipeline.
- Command-line interface: `repair4twin download | run | summary`.
- Released results for 3,240 configurations on C-MAPSS FD001 to FD004.
- Scripts that regenerate every CSV-derived figure and table of the paper.
- Regression tests that check the paper's headline numbers.
- Original Google Colab notebook (v2) used for the experiments.
