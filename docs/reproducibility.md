# Reproducibility

## What is released

| Path | Content |
|---|---|
| `results/all_results.csv` | One row per subset, mechanism, rate, seed and repair method (3,240 rows). Schema in [`results_schema.md`](results_schema.md). |
| `results/divergence_all_datasets.csv` | Per-cell Kendall τ with seed-bootstrap intervals, written by the notebook's master results cell. |
| `tables/` | All paper and supplementary tables, generated by `scripts/make_tables.py`. |
| `figures/paper/`, `figures/supplementary/` | All figures at 300 dpi. |
| `figures/source/` | HTML/SVG sources of Fig. 1 and the graphical abstract. |

Trained weights and per-engine prediction archives are not released because of their size. A full run writes them to `runs/<name>/models/` and `runs/<name>/preds/`.

## Hardware and time

The paper's runs used Google Colab with one NVIDIA L4 GPU (24 GB) in bfloat16 precision.

| Stage, per subset | First run | Resumed |
|---|---|---|
| Twin ensemble (5 members, up to 60 epochs) | 8 to 12 min | seconds |
| SAITS, US-GAN, CSDI | 4 to 8, 12 to 25, 25 to 45 min | seconds |
| Harness (3 mechanisms × 3 rates × 10 seeds × 9 methods) | 45 to 75 min | finished blocks skipped |
| **Total, all four subsets** | **about 8 to 12 h** | |

The CSV-based steps (summary, figures, tables, tests) run on any laptop.

## Seeds and determinism

* Global seed 2026 for NumPy, PyTorch, the k-means regimes, the validation split and MICE.
* Corruption masks are seeded from the integers (mechanism id, rate, seed), never from Python's `hash()`.
* cuDNN runs in deterministic mode. GPU kernels in bfloat16 can still differ in the last digits across hardware and driver versions, so a fresh run reproduces the conclusions and close but not bit-identical numbers.

## Software versions

The released results were produced with PyPOTS 1.5, PyTorch 2.3 or newer and scikit-learn 1.5 or newer. The PyPOTS API changes between releases; the CSDI output shape is checked at run time.
