# Notebooks

`self_healing_digital_twins_v2.ipynb` is the Google Colab notebook that produced the released results. Open it in Colab, select an L4 GPU runtime and choose *Run all*. Checkpoints go to `MyDrive/self_healing_twins/`, so a disconnected session resumes on the next *Run all*.

Set `QUICK_RUN = True` in Section 1 for a 25-minute smoke test on FD001.

The package in `src/repair4twin/` contains the same code split into modules, for running outside Colab.
